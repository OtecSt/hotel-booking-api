# Приёмка и защита

Из чистой копии выполните `./mvnw --batch-mode clean verify`, затем
`KEEP_ACCEPTANCE_LOGS=1 ./scripts/acceptance.sh`. Стенд и сценарии описаны
в [README](../README.md). Итоговый балл выставляет ментор.

## Что показать на защите

1. Открыть Eureka и Swagger. Объяснить, какие запросы идут через Gateway и как Booking находит Hotel.
2. Выполнить обычное бронирование. Показать `CONFIRMED`, историю, отмену и освобождение дат. Объяснить, почему повтор с тем же ключом возвращает тот же ID.
3. Показать результат двух параллельных запросов. Один получает `201`, второй получает `409`. Объяснить, какую строку блокирует Hotel и где проверяются пересечения.
4. Показать тест потери ответа. Hotel трижды подтверждает тот же резерв, а тестовый прокси скрывает ответы. Booking ставит `CANCELLED`. Пока прокси блокирует освобождение, номер занят. После восстановления связи фоновая компенсация освобождает его. По `bookingId` можно найти цепочку в журналах.
5. Показать два номера за десять ночей. Первый забронирован один раз на восемь ночей, второй трижды по одной. Объяснить, почему у них загрузка 80% и 30%.
